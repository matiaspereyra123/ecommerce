# 🛒 Mi Ecommerce (Node.js + Express)

Proyecto personal para aprender desarrollo web backend y frontend.

## 🚀 Tecnologías

- Node.js
- Express.js
- EJS

## 📦 Funcionalidades actuales

- Servidor con Express
- Renderizado de vistas con EJS
- Layout con partials (header y footer)

## 🛠️ Cómo ejecutar el proyecto

```bash
npm install
